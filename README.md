# 🎨 محلل التصاميم (Design Analyzer)

تطبيق ويب بسيط يساعد المصممين والهواة على اكتشاف مشكلات تصاميمهم. ترفع صورة، فيعرض لك:

- فحص **السطوع** و**التباين** مع تنبيهات بالمشكلات
- استخراج **الألوان السائدة** في التصميم
- **خريطة سطوع** توضح توزيع المناطق الفاتحة والداكنة
- نسخة **محسّنة تلقائياً** (فقط عند الحاجة) قابلة للتحميل

> المشروع قيد التطوير. الفحوصات الحالية أساسية، والخطة تشمل فحص تباين النص (WCAG) والتوازن والمحاذاة وتناسق الألوان.

## التشغيل

```bash
git clone https://github.com/M253-coder/design-agent.git
cd design-agent
python -m venv .venv
source .venv/bin/activate      # على ويندوز: .venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py
```

## الاختبارات

```bash
pip install pytest
pytest
```

## هيكل المشروع

| الملف | الوظيفة |
|---|---|
| `app.py` | واجهة Streamlit |
| `analysis.py` | دوال التحليل (بدون واجهة، سهلة الاختبار) |
| `tests/` | اختبارات pytest |
